## 原生 IP 不等于住宅 IP，这两件事别混

LightLayer 洛杉矶机房默认配原生 IP，香港、台湾、新加坡机房是非原生 IP，这是官方促销页面明确写的。原生 IP 的价值在于 IP 注册信息归属当地，Netflix 这类按 IP 归属判定地区的服务更容易认它是本地用户。

但它和"住宅 IP"是两回事。判断一个 IP 是不是住宅属性，要看 ipinfo.io 里 ASN 和 Company 两个字段是不是都显示 ISP（也就是常说的双 ISP），显示 Hosting 或 Datacenter 就还是机房 IP。LightLayer 的公开资料只承诺原生 IP，没有任何一处写双 ISP 或住宅 IP。做 TikTok 美区运营、亚马逊多店铺、ChatGPT 这类对 IP 类型敏感的业务，别默认它能过。

**到手后按三步验，别信单一工具：**

1. 用 ipinfo.io 查 IP，看 `type` 字段和 ASN、Company 的归属，记下结果截图。
2. 用 scamalytics.com 查风控分，分数越低越好。
3. 直接拿目标平台实测，注册或登录一次，能正常用再考虑续费。

单一检测工具的结果容易被针对性优化，多找一两个工具交叉看，再对照路由轨迹是否落在当地运营商网络里，判断才靠得住。第三方测评里有人提过"市面上不少号称家宽的机器只是检测显示双 ISP、IP 其实是广播段"这类说法，属于个人判断没有统计数据支撑，当作提醒就好：任何商家给的 IP 属性，都要自己验一遍。
